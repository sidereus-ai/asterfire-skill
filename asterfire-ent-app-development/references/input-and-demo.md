# 输入、后台归档与可运行示例

当输入含多个文件、底层要求 ZIP、示例不透明或参数难懂时读取。这里的归档只做传输适配，不做科学计算。

## 从真实契约设计表单

开发前记录一份紧凑映射，放在应用现有设计/交接资料中即可，不要求新建固定文件：

| 契约信息 | 页面与后端的决定 |
|---|---|
| 用户要回答的研究问题 | 用用户任务命名页面、主操作和结果；不要照搬 toolbox 名 |
| 必需/可选输入、类型、范围、单位 | 中文标签、紧邻解释、有效样例；缺项提示定位到具体字段 |
| 文件角色、格式及内容要求 | 普通文件入口；示例可下载/预览；同名文件仍保留独立身份 |
| 归档内文件名、目录及配置 | 后端维护的固定映射，不让用户制作 ZIP、JSON 或填相对路径 |
| 链/样本/表格之间的引用关系 | 前端即时提示，服务端再次校验；不静默丢文件/替换含义 |
| 输出端口与证据含义 | 决定报告、表格、图形、结构及缺失项如何呈现 |

数值默认值必须来自已验证契约或明确依据；无法安全推断的必需科学参数不能乱填。必要时询问真正缺失的领域信息，继续推进无关工作。高级选项可收起，解释放在字段旁/帮助抽屉，不铺满接口术语。

例如底层接受 `project.zip`，归档中有数据文件、样本设计 CSV 和配置 JSON：页面提供“实验数据”“样本分组”和带单位的条件字段；可直接编辑小表格并由后端生成 CSV/JSON，或上传普通 CSV。页面不提供 `project.zip` 上传入口，也不要求用户知道配置文件名。此例只说明设计方法，目录与格式必须按实际流程核对。

## 后端归档适配

1. 查明当前 SDK 与 toB 支持的本地文件上传、文件引用、服务端读取/暂存和 Workflow 输入方式；按真实接口做一个小的文件往返验证。`FileSourceButton` 的 local 回调只是浏览器 `File`，不能当作已上传。
2. 表单保存用户值和普通文件选择；提交时固定本次快照，使用平台受权传输把文件交给后端。页面可以读取必要的文本供预览，不能在浏览器压成 ZIP 来替代后端归档。
3. 后端核对文件数量、大小、格式、必需内容、引用完整性和编码，按允许的角色分配安全路径；拒绝目录穿越、同一归档路径冲突及不受支持内容。错误指向具体用户字段，不只吐出底层堆栈。
4. 由 handler/当前受支持的文件服务/异步传输适配生成归档，配置与数据文件来自同一快照；验证生成的目录、必需文件及引用可被真实入口读取。不要编造 `ctx.pack_project`、上传端点或不存在的 SDK 方法。
5. 使用真实输入节点契约传递归档内容/文件引用，并提交一次 Kit/Workflow。云盘引用可复用为额外来源，但本地路径必须不依赖用户先去云盘建目录或上传 ZIP。
6. 大文件/压缩超出同步 handler 预算时走平台已支持的异步传输。若平台没有受支持通道，给出最小缺失接口及可审阅适配方案，如实标为尚未完成；不能用“请用户先打包上传”作为完成方案。

不要把科学参数推导、统计计算或多个 Kit 的有序调度塞进这个适配层。批处理依赖应属于 Workflow。文件字节与压缩内容不塞进 Agent 提示词；日志与记录只留必要摘要、受权引用、哈希/版本和参数快照。

## 示例的唯一行为路径

- 提供小而完整、可合法分发的普通示例文件和有效参数，标明来源、合成实验数据及适用范围。示例必须适配当前真实模板版本；不依赖开发者私有云盘路径。
- “载入示例”只设置与用户手填共用的表单状态、文件选择及必要 UI 展开状态。加载后显示实际值、单位、文件名、内容预览；用户能更换/删除文件、修改字段。不要在另一套隐藏 state 或硬编码提交函数里保留原示例参数。
- 加载、替换、重置、切换历史/新分析时清理相应过期文件引用、缓存的归档、旧结果归属与派生参数。若展示上一轮结果，明确标注其原 run，不能随新表单编辑改变其解释。
- “开始分析”对屏幕上的当前快照校验并走同一个后端归档/提交入口。合理的上传、归档、排队进度应可见；失败允许更正并重试。按钮禁用必须给出具体原因及补齐方式。
- 可另设“查看已完成示范报告”，但明确是历史示范，与本次真实运行分开。完整结果有缺失时如实说明，不生成看似真实的补齐数值。

## 有意义的验收

根据当前修改范围选择检查；新 App 完整交付需覆盖整条真实链路：

| 场景 | 通过证据 |
|---|---|
| 空白进入 → 载入示例 | 一次点击填满必需字段与普通文件；无计算提交；关键区块可见 |
| 示例修改一个参数/换一个文件 → 提交 | 实际入参、归档内容与修改后的可见值一致；旧示例值未暗中覆盖 |
| 清空/重置 → 自己的本地文件 | 没有旧示例或历史文件混入；无 ZIP/云盘前置要求 |
| 缺文件、格式错误、上传/归档失败 | 友好错误、可修复，未提前提交计算；不能永久灰按钮 |
| 重复点击/刷新/未知提交结果 | 不意外重复派活；记录与页面恢复到正确 run，先核对已有提交 |
| toB 真实运行 | 已授权运行实际完成；输入、节点终态、产物 ID 可追溯 |
| 回流与交互 | 报告/表格/结构可读，数据入库，历史与参数快照对应；追问引用真实证据 |
| 计算失败/取消、报告尚未生成 | 页面及时显示真实终态；不继续宣称正在整理报告或成功 |
| 主题、视觉、状态隔离 | indigo/用户指定主题一致；本地实际查看；别的 App 不继承本应用 run |

保留简洁证据：版本、测试范围、实际 run 标识/终态、文件传递与入库结果及未验证项。不要把当前技能创建当作线上测试授权。
